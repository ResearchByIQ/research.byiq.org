The problem

Trust in a protocol is not trust in an operator.

The cryptography behind Signal's messaging is settled and open. What an organisation or a state cannot always accept is that the service is run somewhere else, under someone else's law, on infrastructure it does not control.

The result is a false choice: use the trusted protocol on terms set abroad, or fall back to weaker tools that happen to run at home. The guarantee and the jurisdiction have been bundled together when they need not be.

The approach

Move the operator, keep the guarantee.

01

The protocol, unchanged

Forticom runs the same end-to-end encrypted messaging protocol, so the security properties users already rely on are preserved exactly — no bespoke cryptography, no reduction in the guarantee.

02

Operated where it matters

The deployment lives inside the jurisdiction that depends on it, on infrastructure that jurisdiction controls, so governance and custody sit with the party accountable for them.
